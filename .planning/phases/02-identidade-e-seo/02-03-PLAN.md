  <action>
Create the file `public/favicon.svg` with the following exact content. No build step required — this is a static SVG file served directly:

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64">
  <rect width="64" height="64" rx="12" fill="#2a42ec"/>
  <text
    x="32"
    y="44"
    font-family="Helvetica Neue, Arial, sans-serif"
    font-size="28"
    font-weight="bold"
    text-anchor="middle"
    fill="#ffffff"
  >RIA</text>
</svg>
```

Design decisions:
- `rx="12"` — rounded corners match modern browser tab favicon rendering
- `viewBox="0 0 64 64"` — standard favicon resolution reference
- Font: `Helvetica Neue, Arial, sans-serif` — web-safe stack, no external font needed
- `font-size="28"` — fits "RIA" within 64px without clipping
- `text-anchor="middle"` with `x="32"` — horizontally centered
- `y="44"` — vertically centered accounting for font baseline (approximate midpoint for this size)
- Background `#2a42ec` matches --color-cta token (per D-13)
- Text `#ffffff` for maximum contrast on dark blue

Note: The `<link rel="icon" href="/favicon.svg">` tag is added to index.html by Plan 02. This plan only creates the SVG file.
